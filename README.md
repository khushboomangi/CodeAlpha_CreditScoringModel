# Credit Scoring Model — CodeAlpha Machine Learning Task 1

## 📌 Project Overview
This project predicts an individual's creditworthiness (Credit Risk) based on historical financial data using Machine Learning techniques. The model classifies individuals into high-risk or low-risk categories to assist financial institutions in credit decision-making.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn

## 📊 Workflow
1. **Data Preprocessing & Encoding:** Handled missing values and encoded categorical variables using `LabelEncoder`.
2. **Feature Scaling:** Applied `StandardScaler` to normalize numerical features.
3. **Model Building:** Trained a `RandomForestClassifier` on 80% of the dataset.
4. **Evaluation:** Assessed model performance using Accuracy, Precision, Recall, F1-Score, ROC-AUC, and Confusion Matrix.

## 📈 Model Performance
- **Accuracy:** High classification efficiency
- **ROC-AUC Score:** Strong discrimination capability between good and bad credit risks
